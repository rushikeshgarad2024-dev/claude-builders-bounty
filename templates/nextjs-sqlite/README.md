# Next.js 15 + SQLite SaaS Template

Production-grade Next.js 15 App Router + SQLite architecture guide and `CLAUDE.md` template for AI-assisted SaaS development.

## Setup
1. Copy `CLAUDE.md` into the root of your new or existing Next.js + SQLite repository.
2. Claude Code will automatically ingest this file to understand the architecture, database rules, pragmas, and directory conventions without needing repetitive prompting.

## Example Schema Included
See `example-schema.sql` for production Drizzle/SQLite schema conventions including WAL mode, UUIDv7 keys, and foreign key indices.
